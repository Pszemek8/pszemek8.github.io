# Strona Pszemka

Prosta strona zbudowana w HTML, CSS i JavaScript, gotowa do publikacji na GitHub Pages.

## Pliki
- `index.html` — zawartość strony
- `style.css` — kolory, układ i wygląd
- `script.js` — menu mobilne i aktualny rok w stopce

## Jak opublikować stronę na GitHub Pages
1. Zaloguj się na GitHubie.
2. Kliknij **New repository** (nowe repozytorium).
3. Nazwij repozytorium `pszemek-8.github.io` jeśli chcesz mieć adres `https://pszemek-8.github.io/` (nazwa konta musi być dokładnie taka jak Twój login). Jeśli robisz zwykłe repozytorium, np. `moja-strona`, adres będzie zwykle `https://TWOJ-LOGIN.github.io/moja-strona/`.
4. Ustaw repozytorium jako **Public** i utwórz je.
5. W repozytorium kliknij **Add file → Upload files**.
6. Wgraj `index.html`, `style.css` i `script.js` (możesz też wgrać plik README.md).
7. Kliknij **Commit changes**.
8. Otwórz **Settings → Pages**.
9. W sekcji publikacji wybierz **Deploy from a branch**, gałąź `main` i folder `/ (root)`, potem kliknij **Save**.
10. Poczekaj chwilę i odśwież stronę Settings → Pages — GitHub pokaże adres strony.

## Jak zmienić stronę
- Teksty zmieniaj w `index.html`.
- Kolory i wygląd zmieniaj w `style.css`, w sekcji `:root` na samej górze.
- Zachowanie przycisków i menu zmieniaj w `script.js`.

Wskazówka: nazwy plików muszą być dokładnie takie, jak powyżej. `index.html` musi znajdować się w głównym folderze repozytorium.
